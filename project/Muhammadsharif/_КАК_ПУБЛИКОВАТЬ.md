# Как выложить проект на Hugging Face Spaces (для учеников)

Одинаково для всех трёх проектов. Кода для деплоя не нужно — только загрузить файлы.

## Шаги
1. Зайти на huggingface.co, зарегистрироваться (бесплатно).
2. Справа вверху: **New → Space**.
3. Заполнить:
   - **Space name** — любое имя (например, `homework-time`).
   - **SDK** — выбрать **Gradio**.
   - **Hardware** — CPU basic (бесплатно).
4. Нажать **Create Space**.
5. Вкладка **Files → Add file → Upload files**.
6. Перетащить все файлы из папки своего проекта:
   - `app.py`
   - `requirements.txt`
   - `README.md`
   - и `.pkl`-файлы, если проект их требует (см. ниже).
7. Нажать **Commit**. Space соберётся за 1–2 минуты и заработает по постоянной ссылке.

## Какие .pkl нужны
- **Время на ДЗ** (`homework_time`) — ничего, модель обучается сама при старте.
- **Матзаблуждения** (`math_misconception`) — загрузить `math_misconception_model.pkl` и `answers.pkl`.
- **Цена авто** (`car_price`) — загрузить `car_model.pkl`
  (в ноутбуке сохранить: `joblib.dump(model, "car_model.pkl")`).

## Частые причины, почему Space "не поднимается"
1. **Нет `requirements.txt`** или в нём не хватает `gradio` / `scikit-learn` → в логах ошибка import.
2. **Разные версии scikit-learn.** Если `.pkl` сохранён в Colab на одной версии, а Space ставит другую —
   при загрузке будет предупреждение или ошибка. Решение: в Colab посмотреть версию
   `import sklearn; print(sklearn.__version__)` и вписать её в requirements.txt, например:
   `scikit-learn==1.5.2`
3. **Забыли загрузить .pkl** → `FileNotFoundError` в логах.
4. **Токены в коде.** Никаких Telegram/HF токенов в app.py. Если нужен секрет —
   вкладка Settings → Secrets у Space.

Логи сборки смотреть во вкладке **Logs** самого Space — там видно причину любой ошибки.
