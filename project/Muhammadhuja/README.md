# Предсказание правильности ответа (MathE)

Мой проект по машинному обучению. По теме задачи, уровню сложности и стране студента
модель предсказывает, ответит он **верно** или **неверно**.

## Зачем это нужно

Если заранее видеть, где студенты чаще ошибаются (по темам и уровню сложности),
преподаватель может уделить этим темам больше внимания. Моя модель — маленький шаг
в эту сторону.

## Как это работает

- **Задача:** классификация (верно / неверно).
- **Данные:** датасет MathE — ответы студентов из разных стран на задачи по разным темам.
- **Признаки:** страна студента, уровень задачи (Basic/Advanced), тема, подтема.
- **Модель:** `Pipeline` из OneHotEncoder (кодирует категории в числа) и логистической регрессии.
- **Baseline:** простая модель, которая всегда предсказывает самый частый класс.

## Метрики

| Модель | Accuracy | macro-F1 |
|--------|----------|----------|
| Baseline (самый частый класс) | 0.532 | 0.347 |
| Моя модель (OneHot + LogReg) | 0.590 | 0.580 |

Моя модель заметно лучше baseline по macro-F1 (0.35 → 0.58). Accuracy выросла скромнее,
потому что по одной только теме и стране трудно точно предсказать конкретный ответ —
но модель всё равно улавливает реальные закономерности.

Я смотрю на **macro-F1**, а не только на accuracy, чтобы честно учитывать оба класса
(и верные, и неверные ответы).

## Как пользоваться

1. Выберите страну, уровень, тему и подтему.
2. Нажмите кнопку.
3. Приложение покажет прогноз (верно/неверно) и уверенность модели.

## Стек
