Урок 16 · Проект «Классификатор моих фото»

Transfer Learning — пошагово и без ошибок

Мы не обучаем сеть с нуля — берём готовую MobileNet, которая уже «видела» миллионы картинок, и доучиваем её на СВОИХ двух категориях за 10 минут. Ловушки здесь другие, чем на прошлом уроке. Ниже — правильный код и рядом типичные ошибки: как узнать и как починить.

📐 Размер под модельMobileNet ждёт фиксированный размер (напр. 160×160×3). Телефонные фото все разные — их надо привести к одному.
🎨 Своя предобработкаНа уроке 15 делили на 255. Здесь — НЕТ! У MobileNet своя preprocess_input.
🧊 Заморозка базыbase_model.trainable = False. Иначе сотрём готовые знания сети — это сердце transfer learning.

Три пункта выше — вся суть урока. Почти все ошибки сегодня = забыли один из них.

1Раскладываем фото по папкам = по классам

Зачем: модель узнаёт категорию по имени папки. Одна папка — один класс. Никаких подписей вручную. Что ждём: аккуратная структура ниже.

my_photos/ ├── еда/ ← сюда 15–20+ фото еды │ ├── 1.jpg │ └── 2.jpg ... └── не_еда/ ← сюда 15–20+ фото «не еды» ├── 1.jpg └── 2.jpg ...
Как загрузить свои фото в Colab: сложи папку my_photos в архив my_photos.zip, затем:
from google.colab import files files.upload() # выбери my_photos.zip !unzip -q my_photos.zip # распакует папки еда/ и не_еда/
✗ А ТАК НЕ НАДО
my_photos/ ├── 1.jpg ← все фото свалены в одну кучу ├── 2.jpg └── 3.jpg ...
Почему ломается: если фото не разложены по папкам-классам, модель не поймёт, где какая категория, и не сможет учиться. Как чинить: ровно две вложенные папки, по одной на класс.

2Загружаем фото как датасет — и сразу приводим к нужному размеру

Зачем: image_dataset_from_directory сам прочитает папки, проставит метки и приведёт все фото к одному размеру. Что ждём: список классов и «пачки» (батчи) картинок.

✓ ПИШЕМ ТАК
import tensorflow as tf IMG = (160, 160) # размер, который ждёт MobileNet train_ds = tf.keras.utils.image_dataset_from_directory( "my_photos", image_size=IMG, batch_size=32, validation_split=0.2, subset="training", seed=42) test_ds = tf.keras.utils.image_dataset_from_directory( "my_photos", image_size=IMG, batch_size=32, validation_split=0.2, subset="validation", seed=42) print("Классы:", train_ds.class_names) # ['еда', 'не_еда']
✗ ОШИБКА A — забыли image_size
train_ds = tf.keras.utils.image_dataset_from_directory("my_photos") # фото останутся разного размера → на обучении вылезет ошибка формы
Почему ломается: нейросеть принимает картинки строго одного размера. Без image_size телефонные фото придут разными — форма не сойдётся. Как чинить: всегда задавай image_size=IMG.
✗ ОШИБКА B — один и тот же seed забыли, train и test пересеклись
Утечка данных (data leakage): если train и test берут случайные фото без одинакового seed, одна картинка может попасть и туда, и туда. Тогда высокая точность — обман: модель проверяют на том, что она уже видела («зазубрил, а не понял»). Как чинить: одинаковый seed и validation_split в обоих вызовах.

3Смотрим глазами — точно ли всё загрузилось

Зачем: старое доброе правило — «не доверяй, посмотри на данные». Что ждём: сетку из 6 фото с подписями классов.

✓ ПИШЕМ ТАК
import matplotlib.pyplot as plt for images, labels in train_ds.take(1): # берём одну пачку for i in range(6): plt.subplot(2, 3, i+1) plt.imshow(images[i].numpy().astype("uint8")) plt.title(train_ds.class_names[labels[i]]) plt.axis("off") plt.show()

4Берём готовую MobileNet и ЗАМОРАЖИВАЕМ её

Зачем: MobileNet уже умеет распознавать края, формы, текстуры — миллионы картинок за плечами. Мы замораживаем эти знания, чтобы обучение их не испортило, и доучиваем только маленькую «голову» под наши 2 класса. Что ждём: trainable = False.

✓ ПИШЕМ ТАК
from tensorflow.keras.applications import MobileNetV2 base_model = MobileNetV2(input_shape=IMG + (3,), include_top=False, # без «родной» головы на 1000 классов weights="imagenet") # с готовыми знаниями base_model.trainable = False # ← СЕРДЦЕ transfer learning: замораживаем базу
✗ ГЛАВНАЯ ОШИБКА УРОКА — не заморозили базу
base_model = MobileNetV2(..., weights="imagenet") # base_model.trainable = False ← забыли эту строку
Почему ломается: при обучении на паре десятков наших фото сеть начнёт «переучивать» миллионы своих весов — сотрёт готовые знания, будет учиться очень долго и переобучится (запомнит именно наши фото). Как чинить: обязательно base_model.trainable = False.

5Предобработка: НЕ делим на 255!

Зачем: MobileNet обучали на числах в диапазоне [−1; 1], а не [0; 1]. У неё для этого есть своя функция preprocess_input. Что ждём: предобработка встроена прямо в модель.

✓ ПИШЕМ ТАК
from tensorflow.keras.applications.mobilenet_v2 import preprocess_input from tensorflow.keras import layers, Input, Model inputs = Input(shape=IMG + (3,)) x = preprocess_input(inputs) # приводит к [-1; 1] — как ждёт MobileNet x = base_model(x, training=False) # база работает, но не учится
✗ ОШИБКА — привычка с прошлого урока
x = inputs / 255.0 # на уроке 15 так было верно, здесь — НЕТ
Почему ломается: сеть ждёт диапазон [−1; 1], а получает [0; 1] — как выучить язык, а услышать похожий, но другой. Точность падает без явной ошибки. Правило: у каждой готовой сети — своя preprocess_input. Смотри её, а не дели на 255 «по привычке».

6Достраиваем «голову» и обучаем

Зачем: заморозили базу — теперь добавляем маленький «мозг» под 2 наших класса. Метки у нас целые числа → используем sparse_categorical_crossentropy (стандарт курса). Что ждём: обучение за пару эпох, высокая точность.

✓ ПИШЕМ ТАК
x = layers.GlobalAveragePooling2D()(x) # сжимаем карты признаков в вектор x = layers.Dropout(0.2)(x) # защита от переобучения outputs = layers.Dense(2, activation="softmax")(x) # 2 класса model = Model(inputs, outputs) model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", # метки — числа 0/1 metrics=["accuracy"]) model.fit(train_ds, validation_data=test_ds, epochs=3)
✗ ОШИБКА — Flatten вместо GlobalAveragePooling2D
Почему плохо: Flatten после MobileNet раздувает число параметров в сотни тысяч → медленно и легко переобучается. Как чинить: для transfer learning почти всегда GlobalAveragePooling2D — компактно и стабильно.

7Честная проверка — на НОВОМ фото, которого сеть не видела

Зачем: это «вау»-момент урока. Проверяем не на обучающих фото, а на свежем снимке. Важно: предобработка уже встроена в модель — поэтому фото подаём как есть, второй раз preprocess_input НЕ применяем.

✓ ПИШЕМ ТАК
import numpy as np from tensorflow.keras.utils import load_img, img_to_array img = load_img("test.jpg", target_size=IMG) # тот же размер! arr = img_to_array(img) arr = np.expand_dims(arr, 0) # (1, 160, 160, 3): одна картинка в «пачке» pred = model.predict(arr)[0] print("Ответ:", train_ds.class_names[np.argmax(pred)], f"({pred.max():.0%} уверенности)")
Частые промахи здесь: забыли target_size → неверная форма; забыли expand_dims → модель ждёт «пачку», а не одну картинку; проверяют на обучающем фото → результат ничего не доказывает (утечка).

★Готовый шаблон — запусти с нуля (демо-датасет 2 класса)

📋 Самодостаточно: скачивает демо-набор кот/собака и обучается. Свои фото — та же структура папок, просто поменяй путь.
# ===== TRANSFER LEARNING: КЛАССИФИКАТОР ФОТО — ПОЛНЫЙ ШАБЛОН ===== import os import tensorflow as tf from tensorflow.keras import layers, Input, Model from tensorflow.keras.applications import MobileNetV2 from tensorflow.keras.applications.mobilenet_v2 import preprocess_input IMG = (160, 160) # 1. Данные: демо-набор из 2 классов (кот/собака). Свои фото — та же структура папок. url = "https://storage.googleapis.com/mledu-datasets/cats_and_dogs_filtered.zip" zip_path = tf.keras.utils.get_file("cats_and_dogs.zip", origin=url, extract=True) base = os.path.join(os.path.dirname(zip_path), "cats_and_dogs_filtered") train_ds = tf.keras.utils.image_dataset_from_directory( os.path.join(base, "train"), image_size=IMG, batch_size=32, shuffle=True) test_ds = tf.keras.utils.image_dataset_from_directory( os.path.join(base, "validation"), image_size=IMG, batch_size=32, shuffle=True) print("Классы:", train_ds.class_names) # 2. Готовая MobileNet + заморозка base_model = MobileNetV2(input_shape=IMG + (3,), include_top=False, weights="imagenet") base_model.trainable = False # 3. Модель: своя предобработка (НЕ /255) + голова inputs = Input(shape=IMG + (3,)) x = preprocess_input(inputs) x = base_model(x, training=False) x = layers.GlobalAveragePooling2D()(x) x = layers.Dropout(0.2)(x) outputs = layers.Dense(2, activation="softmax")(x) model = Model(inputs, outputs) # 4. Метки — числа → sparse (стандарт курса) model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"]) # 5. Обучение (база заморожена → быстро) model.fit(train_ds, validation_data=test_ds, epochs=3)

✅ Проверь себя (5 вопросов)

  1. Что такое transfer learning своими словами? Почему это быстрее, чем учить сеть с нуля?
  2. На уроке 15 мы делили картинки на 255.0, а здесь — нет. Почему? Что делаем вместо этого?
  3. Зачем нужна строка base_model.trainable = False? Что случится, если её забыть?
  4. Почему все фото приводим к одному размеру (160, 160), хотя телефонные снимки разного размера?
  5. Друг проверил модель на тех же фото, на которых обучал, и получил 100%. Почему это ничего не доказывает?
Показать ответы (для преподавателя)
  1. Берём сеть, уже обученную на миллионах картинок, и доучиваем маленькую часть под свою задачу. Быстрее, потому что «фундамент» (распознавание краёв, форм, текстур) уже готов — учим только «голову».
  2. MobileNet обучали на диапазоне [−1; 1], а не [0; 1]. Поэтому вместо деления на 255 используем её родную preprocess_input. У каждой готовой сети своя предобработка.
  3. Она замораживает готовые знания базовой сети. Без неё обучение на паре десятков фото сотрёт эти знания, пойдёт медленно и переобучится.
  4. Нейросеть принимает вход строго фиксированной формы. Разные размеры не сойдутся с input_shape модели.
  5. Это утечка данных: модель проверяют на том, что она уже «зазубрила». Честная оценка — только на новых, невиданных фото.
