🎯 Цель: приложение живёт в интернете ВСЕГДА, ссылку можно отправить родителям и добавить в портфолио.

Сначала — файлы приложения (создаются в Colab)

app.py — код приложения

import gradio as gr, joblib

model = joblib.load("penguin_model.joblib")
def predict(bl, bd, fl, bm):
    p = model.predict_proba([[bl, bd, fl, bm]])[0]
    return {c: float(x) for c, x in zip(model.classes_, p)}

gr.Interface(fn=predict,
    inputs=[gr.Number(), gr.Number(),
            gr.Number(), gr.Number()],
    outputs=gr.Label()).launch()

requirements.txt — библиотеки

gradio
scikit-learn
joblib
📦 Третий файл — penguin_model.joblib (сохранён в Colab через joblib.dump). Его тоже загружаем на Spaces рядом с кодом.
⚠️ В app.py для Spaces НЕ пиши share=True — публичный адрес там даётся сам.

6 шагов деплоя

ШагЧто делаешьЧто нажать / ввести
1 Заходишь на сайт и входишь в аккаунт huggingface.co → Log in
2 Создаёшь новое пространство аватар → New Space
3 Заполняешь: имя, тип, доступ name → любое · SDK → Gradio · Public → Create Space
4 Открываешь загрузку файлов вкладка Files → Add file → Upload files
5 Загружаешь ВСЕ ТРИ файла и сохраняешь app.py + requirements.txt + penguin_model.joblib → Commit changes
6 Ждёшь сборку и открываешь приложение вкладка App → ждёшь «Building» 2–3 мин → готово!
✅ Твоя постоянная ссылка: huggingface.co/spaces/ТВОЙ_ЛОГИН/имя-приложения — открывается с любого телефона.

Если не запустилось — не паникуй
