Анализ текста: считаем слова
Часть 4
Данные и проект

Чему научимся

  • Разбивать текст на слова командой split
  • Считать количество слов и находить самое частое
  • Соединять строки, списки и словари для анализа
📚

Текст как данные

Программы умеют не только хранить текст, но и анализировать его: сколько слов, какое встречается чаще всего. Так работают поисковики и умные помощники. У тебя уже есть все инструменты — строки, списки, словари. Осталось соединить.

На пальцах. Представь, что рассыпал текст на отдельные слова-карточки. Теперь можно их посчитать, разложить по стопкам, найти самую большую стопку. Именно это делает анализ текста.
💻

Разбираем код

split разбивает строку на список слов:

analiz.py
text = "кот пёс кот рыба кот пёс"
words = text.split()      # список слов

print("Всего слов:", len(words))

# считаем каждое слово в словарь
count = {}
for word in words:
    if word in count:
        count[word] = count[word] + 1
    else:
        count[word] = 1

print(count)
На экране появитсяВсего слов: 6
{'кот': 3, 'пёс': 2, 'рыба': 1}

Цикл идёт по словам. Если слово уже в словаре — прибавляем 1, если нет — начинаем с 1. В итоге словарь показывает, сколько раз встретилось каждое слово. «кот» — 3 раза, чемпион.

Важно запомнить

split() — разбивает строку на список слов по пробелам. Приём «считать в словарь» (есть ключ — прибавь, нет — создай) очень частый: так считают что угодно — слова, голоса, товары.

✋ Задание в паре

Анализатор предложения

Программа спрашивает предложение и выводит: сколько всего слов и сколько среди них разных (подсказка: разных — это len(count)).

Через 10 минут поменяйтесь ролями.

⚠️

Частые ошибки

Так не работает
А так правильно
count[word] = count[word] + 1
# для нового слова — ошибка
if word in count: ...
else: count[word] = 1

Нельзя прибавлять к слову, которого ещё нет в словаре. Сначала проверь, есть ли оно.

Защита от ошибок: try / except
Часть 4
Данные и проект

Чему научимся

  • Ловить ошибки, чтобы программа не падала
  • Использовать try и except
  • Делать программы надёжными для любого пользователя
📚

Программа не должна падать

Что будет, если в калькуляторе на вопрос «введи число» пользователь напишет «привет»? Программа рухнет с ошибкой. Настоящие программы так себя не ведут — они ловят ошибку и вежливо просят повторить. Это делают слова try и except.

На пальцах. try / except — это страховка. «Попробуй (try) сделать. Если не вышло (except) — вот запасной план». Как страховочный трос у скалолаза: сорвался — не упал, а повис.
💻

Разбираем код

zaschita.py
try:
    age = int(input("Сколько тебе лет? "))
    print("Через год будет:", age + 1)
except:
    print("Это не похоже на число!")
Если ввести «привет»Это не похоже на число!
(программа не рухнула, а вежливо ответила)

Код внутри try — то, что пробуем сделать. Если там ошибка — Python не падает, а прыгает в except и выполняет запасной план. Пользователь видит понятное сообщение, а не красную простыню ошибки.

Важно запомнить

try: — рискованный код. except: — что делать при ошибке. Особенно полезно с int(input()), делением (вдруг на ноль) и файлами (вдруг нет файла).

Приложение 2

📖 Словарь терминов

Простыми словами — все понятия, которые встретились за год.

Программа
Список команд для компьютера, которые он выполняет по порядку.
Переменная
Подписанный «ящик» для хранения значения. Кладёшь по имени, достаёшь по имени.
Строка
Текст в кавычках. «привет», «Худжанд» — это строки.
Число
То, с чем можно считать. Бывает целым (15) и дробным (3.14).
Условие
Проверка «если … иначе …», по которой программа выбирает действие (if / else).
Цикл
Повторение команд: for (по счёту) или while (пока условие верно).
Список
Много значений в одном ящике, пронумерованных с нуля. В квадратных скобках [ ].
Словарь
Пары «ключ — значение». Ищешь по ключу-имени, а не по номеру. В фигурных скобках { }.
Функция
Своя команда с именем, созданная через def. Описал раз — вызываешь сколько нужно.
Аргумент
Данные, которые передаёшь функции при вызове: summa(2, 3) — тут 2 и 3.
return
Слово, которым функция отдаёт результат наружу, чтобы его можно было использовать.
Файл
Место, где данные хранятся и после закрытия программы. Открывают через open.
Модуль
Набор готовых команд, который подключают словом import. Например, turtle, random.
Отступ
4 пробела перед командой. Показывает, что она внутри if, цикла или функции.
Ошибка (Error)
Сообщение Python о проблеме в коде. Не провал, а подсказка, что и где поправить.
