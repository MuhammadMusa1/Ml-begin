Часть 2
Структуры и функции

Чему научимся

  • Хранить много значений в одном списке
  • Брать элементы по номеру и добавлять новые командой append
  • Узнавать длину списка
📚

Зачем нужны списки

Пока в каждый ящик-переменную мы клали одно значение. А если нужно хранить пять оценок? Заводить g1, g2, g3, g4, g5 — неудобно. Есть решение получше: список — один ящик, куда помещается сразу много значений.

На пальцах. Переменная — это один ящик. Список — это полка с пронумерованными ячейками. Всё лежит вместе, а каждая ячейка со своим номером. Считаем с нуля: первая ячейка — номер 0.
💻

Разбираем код

Список создаётся квадратными скобками, элементы через запятую:

spiski.py
fruits = ["яблоко", "банан", "дыня"]

print(fruits[0])          # яблоко — первый
print(fruits[2])          # дыня — третий
print(len(fruits))       # 3 — сколько всего

fruits.append("виноград")  # добавить в конец
print(fruits)
На экране появитсяяблоко
дыня
3
['яблоко', 'банан', 'дыня', 'виноград']

Как и у строк, счёт с нуля: fruits[0] — первый элемент. len говорит, сколько всего элементов. А append добавляет новый в конец списка.

Важно запомнить

Список — в квадратных скобках [ ]. Элементы нумеруются с нуля. append — «добавь в конец». len(список) — сколько элементов внутри.

Часть 2
Структуры и функции

Чему научимся

  • Перебирать список циклом for
  • Считать сумму, среднее, находить максимум
  • Обрабатывать оценки целого класса
📚

Список + цикл = сила

На уроке 5 мы перебирали числа через range. Но for умеет перебирать и список напрямую — брать по очереди каждый элемент. Это соединяет две вещи, которые мы уже знаем, и открывает настоящую обработку данных.

На пальцах. Представь стопку тетрадей. Цикл for берёт по одной тетради сверху, что-то с ней делает, кладёт, берёт следующую — пока стопка не кончится. Список — это стопка, for — твои руки.
💻

Разбираем код

Считаем средний балл по оценкам класса:

ocenki.py
grades = [5, 4, 5, 3, 4]

total = 0
for grade in grades:
    total = total + grade

print("Сумма:", total)
print("Средний балл:", total / len(grades))
print("Лучшая оценка:", max(grades))
На экране появитсяСумма: 21
Средний балл: 4.2
Лучшая оценка: 5

Цикл берёт каждую оценку и прибавляет к total. После цикла делим сумму на количество — получаем среднее. А max сам находит наибольшее число в списке (есть и min — наименьшее).

Важно запомнить

for x in список — берёт каждый элемент по очереди. Чтобы копить сумму, заведи ящик total = 0 до цикла. Готовые помощники: max, min, sum.

Структуры и функции

Чему научимся

  • Создавать свои команды — функции — словом def
  • Передавать в функцию данные (аргументы)
  • Не повторять один и тот же код по многу раз
📚

Зачем нужны функции

Мы уже пользовались готовыми командами: print, input, len. Это функции — маленькие помощники, которые делают одно дело. Оказывается, свои функции можно создавать самому — и это главный способ навести порядок в коде.

На пальцах. Функция — это рецепт с названием. Один раз записал «как заварить чай», а потом просто говоришь «завари чай» — и не пересказываешь все шаги заново. Так и в коде: описал функцию раз — вызываешь её сколько угодно.
💻

Разбираем код

Создаём свою функцию-приветствие словом def:

funkcii.py
def privet(name):
    print("Привет, " + name + "!")
    print("Рады тебя видеть.")

privet("Алишер")
privet("Фарход")
privet("Мадина")
На экране появитсяПривет, Алишер!
Рады тебя видеть.
Привет, Фарход!
Рады тебя видеть.
Привет, Мадина!
Рады тебя видеть.

Строка def privet(name): описывает функцию: её имя privet и что она принимает — name. Тело функции — с отступом. Дальше мы вызываем её три раза с разными именами — и код внутри не пришлось повторять.

Важно запомнить

def имя(данные): — создаём функцию. Тело — с отступом. То, что в скобках при создании — параметр, то, что передаём при вызове — аргумент. Функцию сначала описывают, потом вызывают.

Функции возвращают результат
Часть 2
Структуры и функции

Чему научимся

  • Получать из функции результат словом return
  • Понимать разницу между «напечатать» и «вернуть»
  • Собирать программу из функций-помощников
📚

Печатать или вернуть?

Функции с прошлого урока сами печатали результат. Но чаще нужно, чтобы функция отдала ответ обратно — и мы решили, что с ним делать: напечатать, сохранить в ящик, использовать в расчёте. За это отвечает слово return.

На пальцах. print — это когда повар выносит блюдо и сразу ставит на стол. return — когда повар отдаёт блюдо тебе в руки, а ты сам решаешь: съесть, отнести другу или положить в холодильник. return гибче.
💻

Разбираем код

return.py
def summa(a, b):
    return a + b

# результат можно сохранить в ящик
result = summa(10, 5)
print(result)              # 15

# или сразу использовать в расчёте
print(summa(3, 4) * 2)   # 14
На экране появится15
14

Функция summa не печатает — она возвращает число. Поэтому его можно сохранить в result, умножить, передать дальше. В этом сила return: результат становится обычным значением, с которым можно делать что угодно.

Важно запомнить

return отдаёт результат из функции наружу. После return функция заканчивает работу. Разница: print показывает на экране, return отдаёт значение, которое можно использовать.

📚

Когда списка мало

В списке элементы ищут по номеру: [0], [1]. Но иногда искать хочется по имени: не «третий элемент», а «телефон Алишера». Для этого есть словарь — он хранит пары: ключ (имя) и значение (телефон).

На пальцах. Словарь — как настоящий словарь или телефонная книга. Ты не листаешь по номерам страниц — ты ищешь слово и сразу видишь перевод. Ключ — это слово, значение — его перевод.
💻

Разбираем код

Словарь создаётся фигурными скобками, пары через двоеточие:

slovari.py
phones = {
    "Алишер": "901-234-567",
    "Мадина": "902-345-678",
    "Фарход": "903-456-789"
}

print(phones["Мадина"])   # находим по имени

phones["Сафар"] = "904-567-890"  # добавляем нового
print(phones)
На экране появится902-345-678
{'Алишер': '901-234-567', 'Мадина': '902-345-678', ...}

Вместо номера, как в списке, мы пишем ключ — phones["Мадина"] — и сразу получаем значение. Чтобы добавить новую пару, просто присваиваем значение новому ключу.

Список против словаря

Список [ ] — доступ по номеру: spisok[0]. Словарь { } — доступ по ключу: slovar["имя"]. Список — когда важен порядок, словарь — когда важно найти по названию.

Поле и его показ

Поле — это список из 9 клеток. Функция рисует его сеткой 3×3:

pole.py
board = [" "] * 9   # 9 пустых клеток

def show(board):
    print(board[0], "|", board[1], "|", board[2])
    print("---------")
    print(board[3], "|", board[4], "|", board[5])
    print("---------")
    print(board[6], "|", board[7], "|", board[8])

show(board)

Поле — список из 9 клеток

[" "] * 9 создаёт список из девяти пробелов — пустых клеток. Клетка 0 — верхняя левая.

Функция show рисует поле

Мы вынесли рисование в функцию — теперь можно показать поле в любой момент одной командой show(board).

Теперь ход игрока — ставим знак в выбранную клетку:

hod.py
pos = int(input("Куда ставишь (1-9)? "))
board[pos - 1] = "X"   # игрок назвал 1, а список с 0
show(board)

Важный момент

Игрок называет клетки 1–9, а список считает с 0. Поэтому board[pos - 1]: вычитаем 1, чтобы номер клетки совпал с номером в списке.

Собираем игру целиком

Соединяем поле с прошлого урока, чередование игроков и проверку победы:

krestiki.py
board = [" "] * 9

def show(board):
    print(board[0], "|", board[1], "|", board[2])
    print(board[3], "|", board[4], "|", board[5])
    print(board[6], "|", board[7], "|", board[8])

def winner(b):
    lines = [(0,1,2),(3,4,5),(6,7,8),
             (0,3,6),(1,4,7),(2,5,8),
             (0,4,8),(2,4,6)]
    for a, b2, c in lines:
        if b[a] == b[b2] == b[c] != " ":
            return b[a]
    return None

player = "X"
for turn in range(9):
    show(board)
    pos = int(input(player + ", клетка (1-9): "))
    board[pos - 1] = player
    if winner(board):
        show(board)
        print(player + " победил!")
        break
    player = "O" if player == "X" else "X"

Функция winner проверяет линии

Восемь способов победить: 3 ряда, 3 столбца, 2 диагонали. Функция проверяет каждую линию — три одинаковых знака подряд.

Цикл на 9 ходов

Максимум 9 клеток — значит 9 ходов. После каждого проверяем победу.

Смена игрока

Последняя строка меняет X на O и обратно: "O" if player == "X" else "X".
