📥 Как загрузить свой датасет в Google Colab

Пошаговая инструкция · Курс Machine Learning

🎯 Что ты научишься делать

После этой инструкции ты сможешь тремя способами открыть свой датасет:

  • 📁 Загрузить файл с компьютера
  • 🌐 Подключить датасет по ссылке (URL)
  • ☁️ Подключить Google Drive

👉 Этот навык нужен на каждом уроке до конца курса.

⚙️ Подготовка (сделай 1 раз)

Открой https://colab.research.google.comGoogle Colab → создай новый ноутбук → в первой ячейке напиши:

import pandas as pd
Правило курса: без pandas ни один датасет не откроется. Эта строка всегда идёт первой.
Способ 1 📁 Загрузка файла с компьютера

Используй, если у тебя есть файл .csv на компьютере.

1
Вставь код в новую ячейку:
from google.colab import files
uploaded = files.upload()
2
Нажми кнопку «Выбрать файл» → выбери свой .csv.
3
Открой файл в pandas:
df = pd.read_csv("название_файла.csv")
df.head()
⚠️ Частая ошибка: название файла должно быть точно таким же, как ты загрузил. Если файл называется pokemon_data.csv — пиши именно так, а не pokemon.csv.
✅ Проверка успеха: если ты видишь таблицу с данными — всё сработало.
Способ 2 🌐 Загрузка по URL — самый быстрый

Используй, если датасет лежит в интернете (GitHub, открытые источники).

1
Найди прямую ссылку на файл .csv (заканчивается на .csv).
2
Открой напрямую:
url = "https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv"
df = pd.read_csv(url)
df.head()
✅ Готово! Данные уже в Colab, ничего скачивать не надо.

Как правильно взять ссылку с GitHub

❌ Так НЕ работает (это страница, а не файл):
https://github.com/user/repo/blob/main/data.csv
✅ Так работает (сырой файл):
https://raw.githubusercontent.com/user/repo/main/data.csv

Правило: на GitHub нажми кнопку «Raw» → скопируй ссылку из адресной строки.

Как взять ссылку с Kaggle

Kaggle не даёт прямую ссылку на .csv. Есть два варианта:

  • Простой: скачай .csv с Kaggle → загрузи через Способ 1.
  • Продвинутый: используй Kaggle API (разберём позже отдельно).
Способ 3 ☁️ Через Google Drive

Используй, если датасет большой или ты работаешь с ним долго.

1
Подключи Google Drive:
from google.colab import drive
drive.mount('/content/drive')
2
Colab попросит разрешение → нажми «Разрешить».
3
Загрузи файл в Google Drive (например, в папку ML_course) и открой его:
df = pd.read_csv('/content/drive/MyDrive/ML_course/mydata.csv')
df.head()
✅ Плюс: файл больше не нужно загружать каждый раз.

🔍 Как проверить, что датасет загрузился

Всегда после загрузки выполняй эти 4 команды — это правило курса:

df.shape       # сколько строк и столбцов
df.head()      # первые 5 строк
df.info()      # типы данных
df.describe()  # статистика
Если хоть одна команда выдаёт ошибку — датасет загружен неправильно. Начни заново.

❌ Топ-5 ошибок учеников

Ошибка Причина Решение
FileNotFoundError Неверное имя файла Проверь имя буква-в-букву
UnicodeDecodeError Кодировка файла pd.read_csv(file, encoding='cp1251')
Данные в один столбец Неверный разделитель pd.read_csv(file, sep=';')
HTTPError 404 Ссылка не прямая Используй raw-ссылку
Пустой df.head() Файл пустой или не тот Открой в Excel и проверь
